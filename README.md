## 📁 Featured Projects

<details>
<summary><b>🔥 MetanolReport — Enterprise Industrial Intelligence & Offline-First Desktop Platform (.NET 10 & WPF)</b></summary>

<br />

### Project Overview
A hybrid industrial enterprise intelligence platform engineered to eliminate operational data silos and manual shift transcription in chemical manufacturing plants. Combines a resilient offline-first WPF desktop client with an ASP.NET Core Web API backend.

| Metric / Dimension | Specification Details |
| :--- | :--- |
| **Stack** | `.NET 10` • `WPF` • `ASP.NET Core Web API` • `PostgreSQL (JSONB)` • `SQLite` • `Dapper` • `PdfPig` |
| **Scale** | Multi-plant industrial telemetry ingestion handling tens of thousands of data points per shift |
| **Performance** | Sub-3-second PDF/Excel spatial grid parsing and local `O(1)` SQLite transactional queuing |
| **Security** | JWT-authenticated REST APIs, encrypted local database storage, and signed shift reports |
| **Impact** | **93% reduction** in daily shift operational processing time and **zero data loss** |
| **Repository** | [github.com/reifeiv/metanol-report](https://github.com/reifeiv) |

#### Technical Architecture & Highlights
- **Resilient Offline Synchronization**: Local SQLite storage coupled with Dapper micro-ORM enqueues transactions into a `PendingSyncQueue`. A background worker continuously monitors network telemetry to execute batch sync operations with automatic concurrency conflict resolution.
- **Spatial Document Parsing Engine**: Built a coordinate-based character reconstruction engine using `PdfPig` to parse un-structured shift logs directly into validated domain models, guaranteeing zero manual input errors.

</details>

<summary><b>📱 Lify Mobile App — B2B SaaS Gamified Language Learning Platform (Flutter Native)</b></summary>

<br />

### Project Overview
A native mobile B2B SaaS learning platform built with Flutter. Solved low completion rates in enterprise training through reactive gamification dynamics, daily streak mechanics, and instant lesson pause/resume capabilities.

| Metric / Dimension | Specification Details |
| :--- | :--- |
| **Stack** | `Flutter` • `Dart` • `Firebase Firestore` • `Offline State Cache` • `Android & iOS` |
| **Scale** | Multi-tenant enterprise corporate deployment supporting hundreds of concurrent learners |
| **Performance** | Native 60 FPS UI rendering, low memory footprint, and instantaneous local state restoration |
| **Security** | Firebase Auth token validation, granular Firestore security rules, and encrypted cache |
| **Impact** | Increased course completion rate from <20% to >75% across enterprise teams |
| **Repository** | [github.com/reifeiv/lify-mobile](https://github.com/reifeiv) |

#### Technical Architecture & Highlights
- **Firestore Denormalization Strategy**: Structured user progress inside single-document atomic maps (`learningStats`) accessed via deterministic keys (`${userId}_${lifyFormId}`) for instant $O(1)$ reads.
- **Offline State Resume**: Designed an in-memory & disk state manager that caches `currentBlockId` and user answers in real-time. Allows users to resume uninterrupted even when connectivity drops.

</details>
